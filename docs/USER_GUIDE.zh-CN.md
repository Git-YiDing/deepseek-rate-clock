# DeepSeek Rate Clock 用户指南

[English](USER_GUIDE.md)

## 运行要求

- Apple Silicon Mac（`arm64`）
- macOS 11.0 或更高版本
- 不需要 Python、Conda、API Key 或第三方运行依赖
- 仅打开官方价格页面时需要网络

## 启动和使用

1. 双击 `DeepSeek Rate Clock.app`。
2. 在 macOS 菜单栏右侧查找应用；它没有普通窗口或 Dock 图标。
3. 同时查看圆点颜色和状态文字：
   - 绿色 + `半价`：空闲半价时段。
   - 红色 + `未优惠`：高峰、未优惠时段。
   - 红色 + `待生效`：内置峰谷政策尚未生效。
4. 点击菜单栏项目，查看完整状态、倒计时、当地时间、北京时间、时段规则和官方价格入口。
5. 选择 `退出 DeepSeek Rate Clock` 退出。

当前界面文字为简体中文。

## 内置时段

政策快照核对日期为 2026-08-15：

- 生效时间：北京时间 2026-08-17 00:00。
- 高峰时段：北京时间 `[09:00, 12:00)`、`[14:00, 18:00)`。
- 其他时间为空闲时段；该政策快照将空闲价格定义为高峰价格的 50%。

应用始终使用 `Asia/Shanghai` 判断价格状态；菜单栏时钟显示 Mac 当地时间。

规则内置于应用，不会自动更新。涉及成本的使用请先核对 [DeepSeek 官方价格页面](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

## 开机启动

应用不会自行注册为登录项。如需手动添加，请打开“系统设置”→“通用”→“登录项与扩展”，然后在“登录时打开”中添加应用。

## 隐私

应用不请求 API Key，不保存设置或用户数据，不发送遥测，也不会自动联网。官方价格命令会打开默认浏览器，浏览器可能保留自己的历史记录或缓存。

## 故障排查

### 没有出现窗口

这是正常现象。应用只显示在菜单栏。

### 菜单栏没有应用

菜单栏空间可能被屏幕刘海或其他菜单栏应用占用。减少其他项目后重新打开应用。

### macOS 阻止首次打开

使用临时签名的 GitHub 构建没有经过 Apple 公证。在 Finder 中按住 Control 点击可信的本地应用，选择“打开”并确认。不要全局关闭 Gatekeeper。

### 状态似乎不正确

检查 Mac 的日期和时间，再将内置时段与最新官方价格页面比较。状态依据北京时间，而不是菜单栏显示的当地时间。

## 只读自检

在仓库根目录运行：

```zsh
"build/DeepSeek Rate Clock.app/Contents/MacOS/DeepSeekRateClock" --self-test
"build/DeepSeek Rate Clock.app/Contents/MacOS/DeepSeekRateClock" --status
```

## 卸载

退出应用后将其移到废纸篓。应用不创建偏好设置文件。如果手动添加过登录项，请同时在“系统设置”中移除。
